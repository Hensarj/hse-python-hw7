# Python — домашнее задание 7

Откройте `Python_ДЗ7.ipynb` в Jupyter Notebook или Google Colab и запускайте ячейки по порядку. Нужны интернет и библиотека `requests`.

1. JSONPlaceholder: GET `/posts`, заголовки и тела первых пяти постов. Сохранён настоящий вывод локального запуска.
2. OpenWeather: ввод города, GET с параметрами `q`, `appid`, `units=metric`, `lang=ru`, температура и описание погоды. Введите собственный действующий ключ в скрытом поле при запуске; не записывайте его в код и не публикуйте. Успешный запрос погоды пока не проверен: доступного ключа нет.
